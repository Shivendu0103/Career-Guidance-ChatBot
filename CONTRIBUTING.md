# 🤝 Contributing to Career Guidance Chatbot

Thank you for considering contributing to this project! Your support and contributions help make this chatbot more useful for students across various fields.

## 🛠️ How You Can Help

You can contribute in the following ways:

- 📚 Add new intents to `intents.json` (especially for different career streams)
- 🧠 Improve the NLP pipeline or training model
- 🐛 Report bugs or fix issues
- 🌐 Improve the UI or add multi-language support
- 📄 Improve documentation (README, REPORT, etc.)

## 🧑‍💻 Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/Shivendu0103/Career-Guidance-ChatBot
   
3. Create a new branch:

```bash
git checkout -b your-feature-name
```
4. Make your changes and commit:

```bash
git commit -m "Add: your message"
```
5. Push to GitHub:

```bash
git push origin your-feature-name
```
6. Submit a pull request

✅ Code Guidelines
Follow Python best practices (PEP8)

Keep the code modular and readable

Comment where necessary

Test before submitting

💬 Need Help?
Feel free to open an issue or discussion if you're stuck or unsure where to start!
