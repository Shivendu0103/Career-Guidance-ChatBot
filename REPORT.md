# Career Guidance AI Chatbot – Project Report

## Objective

To build an AI-powered chatbot that helps students explore career options based on their interests, stream, and preferences. The chatbot uses NLP techniques and a trained model to provide tailored guidance.

## Technologies Used

- **Frontend**: Streamlit
- **Backend**: Python, NLTK, Keras
- **Model**: Intent classification via a neural network
- **Deployment**: Streamlit Cloud / Local Server

## Features

- Real-time interaction with users through chat
- Dynamic responses for a wide range of streams: Engineering (CSE, Mech, Civil), Commerce, Arts, Medical, etc.
- Expandable intent system with JSON configuration
- Smooth user experience with input memory handling and rerun suppression

## Challenges Faced

- Deployment without internet: manually handled `punkt` tokenizer
- Repeated input bug resolved via input state management
- Streamlit rerun issue handled gracefully

## Future Work

- Integrate GPT-4 Turbo API for dynamic answers
- Add visual career path suggestions (charts, graphs)
- Multilingual support for regional guidance
